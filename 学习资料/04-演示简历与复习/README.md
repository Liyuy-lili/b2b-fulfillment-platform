## 证据阅读方法

先读阶段报告里的业务结论，再打开对应JSON的`checks`或`rounds`，最后根据源码入口找事务/SQL。`result=passed`必须结合本轮artifact SHA；不同阶段的旧结果不相加冒充本轮覆盖率。60个指定JUnit不等于上游全部测试；T01—T30是30个业务场景，和几百个细粒度断言是不同计数单位。

性能数据只使用M7原始请求与EXPLAIN，不将合成数据写成真实用户量。仓库权限限定于本项目专用入口；给角色附加广泛ERP权限会扩大可见范围。物流为本地签名模拟，文件存储为同机私有目录。
