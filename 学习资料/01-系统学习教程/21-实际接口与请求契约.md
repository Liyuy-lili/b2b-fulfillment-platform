## 编号语义

| 契约 | items中ID指向 |
| --- | --- |
| ReleaseLine.reservationId | ful_reservation.id |
| ShipRequest.items[].id | ful_reservation.id |
| CancelRequest.items[].id | ful_order_item.id |
| CreateRequest退货items[].id | ful_shipment_item.id |

租户/actor/ERP商业字段不由客户端任意指定。分配holdSeconds当前60—86400，候选仓1—16；release/ship/cancel/退货items有实际大小及小数规则，以下原契约是准确来源。

## 教学请求示例（不执行）

数字是格式占位，需换成当前有权访问的真实ID；不同请求中的id不是同一类业务对象。不要直接向已有演示数据重放这些示例。

```json
{
  "orderId": "1",
  "strategy": "PRIORITY_SPLIT",
  "warehouseIds": [
    "1",
    "2"
  ],
  "holdSeconds": 3600
}
```

上例用于preview或allocate；只有allocate需要命令key。

```json
{
  "orderId": "1",
  "shipmentId": "2",
  "items": [
    {
      "id": "3",
      "quantity": "2.000001"
    }
  ],
  "reason": "商品退回"
}
```

上例是退货create，id=原发货项；receive只需要orderId/returnId；reject还需要reason。
