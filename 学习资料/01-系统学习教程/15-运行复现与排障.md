# 15 源码运行、独立包与排障

操作详[独立运行手册](../06-运行交付与证据/独立交付运行手册.md)。本轮仅整理，未启停服务。

源码根目录scripts/Start-Local.ps1、Stop-Local.ps1管理项目应用；-Dependencies会停止本项目依赖。MySQL33306与系统3306不同；Redis36379、前端15173、后端48080、RabbitMQ35672。旧PID不是当前身份，先核对进程路径。

Build.ps1使用-DskipTests，仅打包。V1—V8冻结，已有库不重装/baseline；指定测试与最终回归命令按M7报告前提执行，会创建数据或覆盖部分结果，不作为只读学习动作。

最终包fulfillment-final-20261020-095456.zip，manifest校验、源码外新目录/新schema/Redis DB13/vhost、真实页面与固定演示通过。位置和SHA见[M7报告](../10-验收证据/M7-验收报告.md)。无需Maven/pnpm运行，仍需Java/Node/服务。Install对已有库拒绝，不能重装覆盖。

| 症状 | 先查 |
| --- | --- |
| 连接拒绝 | 监听/端口归属/启动日志，不清库 |
| code非0 | 包装码、tenant/owner/仓库，不只看HTTP |
| 重复单号 | Redis持久化和SQL单号上界，不flush |
| Flyway校验 | 目标库、冻结SQL、历史，不随意repair |
| Outbox积压 | status/lease/version/confirm/return |
| Inbox失败 | RETRY_WAIT/DEAD和投影，ACK不一定副作用完成 |
| 任务等待 | 准入门闩、租户并发、线程池和lease |
| 下载拒绝 | 当前权限/归属、大小/hash，不公开私有路径 |
| 到期延迟 | 有界游标/坏行/租户有效/时钟 |
| 核对差异 | ruleCode/对象/快照/事实，不自动改H/R |

单号修复仅提升当天上界，先暂停ERP写入；消息REPUBLISH与消费RETRY意图不同，保留eventId、原因和审计。每次排障保留原key/请求、前后事实、修复和复验范围；本机正常重启不证明HA/断电容灾。
